## 0. 这轮实验要回答什么

上一轮（12 个模型）已确认：文本可近无损压成多尺度离散码（99.4–99.9%）、层级需要 scale dropout 才会出现、密梯子 bertB=[8..256] 的截断重建坡道最好。**这轮在冻结 Stage 0 tokenizer 之前，验证三件更根本的事**：

1. 混合 schedule [1,8,16,32,64,128,256] 能否兼得"q1 主题锚"与"bertB 坡道"？（Exp 1）
2. 各尺度是**真正多尺度**还是互相冗余？（Exp 2）
3. 严格意义上，**粗码能否降低细码的不确定性**——这是 Stage 1 VAR planner 的核心前提（Exp 3 + prompt 补测）

## 1. 实验设置

共同配置（与上轮 BERT 线完全一致，保证可比）：WikiText-103、bert-base-uncased、N=256、c=1、6L/512d encoder + 8L/512d decoder、共享 VQ-EMA 码本 8192×32d、scale dropout 0.5、50k 步、batch 256、AdamW 3e-4 cosine、bf16、前 5k 步量化旁路、无 φ conv。

对 spec 的两个方法论修正（执行前已确认）：
- **Exp 2 加 subset-readout decoder**：原 decoder 训练时只见过"前缀"输入，直接做留一尺度/单尺度评估是分布外（先例：无 dropout 的 base 截断 PPL 达 170 万）。修正 = 冻结 encoder+码本，把 decoder 复制一份在随机尺度子集上微调 2k 步，用它做可信读数（raw 与 readout 两版都报）。
- **Exp 3 钉死分解方式**：按 VAR/Stage 1 的真实分解测——给定全部粗码，**并行、逐位置条件独立**地预测目标尺度全部码；控制组用**完全相同架构**、把粗码槽换成可学习的空向量（容量与优化完全匹配，差异只来自粗码信息）；另报逐位置 unigram 基线。

作业清单（7 个，全部 SUCCESS）：bertHybrid 训练（run 888990804330228）；bertB 的 Exp2 / Exp3（81671176131787 / 733780106461103）；probe-bertPilot（456093113031659，q1 同 tokenizer 参照）；hybrid 的 probe / Exp2 / Exp3（207135524230190 / 206144172741772 / 484571479481440）；prompt 补测（605558091889954）。

## 2. Exp 1 — 混合 schedule 验证

bertHybrid = [1,8,16,32,64,128,256]（505 码/窗）。

**全量重建**：acc **99.44%**、PPL 1.025 —— 与 bertB（99.43%/1.025）持平；严格按 99.5% 门槛算两者都差 0.06pp（[1,2,4,256] 系列可达 99.85%，密梯子有小幅"重建税"）。

**前缀重建 vs bertB（按最近码数预算对齐）**：

| 预算点 | bertHybrid | bertB | 差 |
|---|---|---|---|
| ~9 码 | 8.7% | 8.9% | −0.2pp |
| ~57 码 | 27.7% | 29.7% | −2.0pp |
| ~121 码 | 50.7% | 52.5% | −1.8pp |
| ~249 码 | 83.0% | 84.4% | −1.4pp |
| 全量 | 99.44% | 99.43% | 持平 |

**q1 语义锚**：相邻窗口 q1 一致率 58.7% vs 随机 2.6% → lift **22.6×**。锚还在，但被稀释——q1 只用了 ~38 个有效码来区分主题（同 tokenizer 参照 bertPilot 的 q1：lift 103.8×、~250 个有效码）。密梯子在身后时，q1 承担的独特压力变小。

**小结**：混合方案≈bertB 加一个小代价（坡道 −1.4~−2pp）换一个被稀释的主题锚。q1 值不值，取决于它对 planner 有没有预测价值——见 Exp 3 的 q1 消融。

## 3. Exp 2 — 逐尺度边际贡献（是否冗余）

**readout 修正被证明必要**：raw 模式把粗尺度的留一损失夸大约 2 倍（如 bertB 去掉 q8：raw −7.7pp vs readout −3.3pp）。以下为可信的 readout 读数。

**留一尺度（LOSO，test acc 相对全量的损失）**：

| 去掉的尺度 | bertB | bertHybrid |
|---|---|---|
| q1 | — | −0.8pp |
| q8 | −3.3pp | −2.4pp |
| q16 | −4.4pp | −3.3pp |
| q32 | −6.7pp | −5.4pp |
| q64 | −9.3pp | −9.4pp |
| q128 | −16.3pp | −17.1pp |
| q256 | −17.2pp | −18.2pp |

**结论：没有冗余尺度**——去掉任何一层都有实质损失，且随该层码数单调增加。邻居组合显示互补而非重叠（bertB：[q64,q128,q256]=66.9%，抽掉中间的 q128 只剩 [q64,q256]=33.1%）。单尺度独立解码普遍很弱（8–23%），这符合残差语义：每层编码的是"更粗层没解释掉的部分"，单独解码差不代表信息少。

## 4. Exp 3 — 严格 next-scale 可预测性（本轮头条）

**核心读数（gain = 控制组 CE − 条件组 CE，bits/码；正 = 粗码有帮助）**：

| transition | bertB | bertHybrid |
|---|---|---|
| →q8（由 q1） | — | +0.00 |
| →q16 | −0.46 | −0.44 |
| →q32 | −0.31 | −0.30 |
| →q64 | −0.16 | −0.20 |
| →q128 | −0.05 | −0.02 |
| →q256 | **+0.08** | **+0.09** |

给 q256 的增量条件同样平坦（1 层粗码 → 5 层：CE 只降 ~0.03 bits）。**hybrid 的 q1 消融给出干脆的零**：条件里加不加 q1，预测 q256 的 CE 一样（12.67 vs 12.69 bits）——q1 没有任何 planner 预测价值。

**prompt 条件补测**（用前一窗原文做 prompt，text-only vs text+粗码容量匹配）：

| transition | 只看 prompt | prompt+粗码 | gain |
|---|---|---|---|
| →q16 | 12.96 | 13.05 | −0.09 |
| →q32 | 12.73 | 12.65 | +0.08 |
| →q64 | 12.97 | 12.95 | +0.02 |
| →q128 | 12.97 | 12.94 | +0.03 |
| →q256 | 12.81 | 12.75 | +0.06 |

**即使有 prompt，增益依然 ≈0**（全部在 931 对验证样本的 ±0.05 bits 噪声内）；且 prompt 本身也几乎不帮忙（12.81 vs 无条件 12.83）——窗口的具体码身份本质上是高熵对象，前文只定得了主题，定不了每个码的取值。

**结构性解释（一个机制解释全部三组现象）**：残差量化的定义就是"第 k+1 层编码前 k 层没解释掉的残差"，因此各层码**天生互相不带对方的信息**——
- 信息正交 → Exp 2 的"无冗余" ✅
- 信息累加 → 截断曲线平滑上升 ✅
- 正交的另一面 → **粗码预测不了细码** ✗

上一轮泛用 AR 探针测到的 +2.05 bits"上下文增益"由此被拆穿：几乎全部来自**尺度内相邻码**的相关性，不是粗→细传递（这正是本轮严格探针的价值）。

打个比方：我们以为造的是"先画草图、再上细节"的画法，实际造出来的是"把一幅画剪成几块分开存"——每块都不可缺，但看着第一块猜不出第二块。

## 5. 冻结判定（need_next3 五条标准）

| # | 标准 | 判定 |
|---|---|---|
| 1 | 全量重建 ≥99.5% | 边缘（hybrid/bertB 99.44/99.43%；pilot 系列 99.8%+ 可过） |
| 2 | 有意义的粗→细前缀重建 | ✅（8% → 83–84% 平滑坡道） |
| 3 | 无明显冗余层级 | ✅（LOSO 全正、单调、邻居互补） |
| 4 | 粗码可测地降低细码不确定性 | **✗（无条件与 prompt 条件双双 ≈0，结构性失败）** |
| 5 | q1 有语义或 planner 价值 | 半：语义有（22.6× 文档一致性）、planner 预测无（消融=0） |

> **最终结论：不冻结。压缩这一半彻底成功；"粗码当草稿引导细码"这一半，当前纯残差设计做不到——但失败原因明确，修的方向也明确。**

## 6. 下一步（Stage 0.5，按推荐顺序）

1. **给 tokenizer 加跨尺度耦合辅助损失后重训**（首选，~6.5h/模型）：训练时加一个小头，用"前 k 层的累计 latent"预测"第 k+1 层的码"，小权重——直接优化 Stage 1 需要的性质；重训一个 bertB-schedule 模型后复测 Exp 3，看增益是否出现。
2. **换 planner 的预测目标**：让 planner 预测**连续的累计 latent**（预测完再查码本量化），绕开"8192 选 1 的近均匀码身份"这个不合理接口——proposal 的 A5 消融（连续 planner）重新变得有吸引力。
3. **非残差金字塔变体**做对照（各层量化"累计"而非"残差"，天然保留跨层相关性，代价是层间冗余）。

若被外部原因逼着立刻冻结：选 **bertB**（q1 既损坡道又无预测价值），但要明确 Stage 1 planner 将面对近独立的高熵码。

## 勘误与最终结论修订（2026-08-11）

**本报告 §4 的负面结论已被推翻**——探针存在两处设计错误（由用户审查发现）：
1. 条件码用从零训练的 id embedding 表示，而非冻结的 pretrained codebook 向量；
2. 目标位置用无内容的可学习 query，而非 VAR 的 e_k（前序尺度累计反量化 latent 的 up-interpolation）。

两处修正后（探针内部重建与 tokenizer 反量化路径逐位一致，有单测锁定），**所有 transition 的增益由 ≈0/负值全面转正**：

| 目标尺度 | bertB（修正后） | bertHybrid（修正后） | 旧探针（bertB） |
|---|---|---|---|
| q16 | +0.14 | +0.08 | −0.46 |
| q64 | +0.24 | +0.35 | −0.16 |
| q128 | +0.33 | +0.54 | −0.05 |
| q256 | **+0.73** | **+1.11** | +0.08 |

prompt 版同步转正（q256：bertB +0.41 / hybrid +0.60）；增量条件强单调（hybrid q256：12.66→11.67 bits）；**q1 消融复验 = +0.07 bits**（原判"零价值"翻案）。

**修订后的冻结判定：五条标准 边缘/✅/✅/✅/✅ → 冻结 bertHybrid**（跨尺度耦合最强 + q1 主题锚 + 重建与 bertB 持平）。tokenizer 不需要手术；Stage 1 的硬性设计约束 = planner 输入接口必须严格按 VAR 构造（偏离即丢失几乎全部跨尺度信号，本轮已实测）。残余熵仍高（q256 条件后 11.7/13 bits），prompt 条件承担其余信息——与 VAR 在图像上的情形同性质。

方法论教训：**负面结论对探针接口极其敏感**。跨尺度信息藏在码本几何与空间对齐里，raw id + 自由 query 的探针在同一批 checkpoint 上测出 ≈0——两版探针结果均已归档（`results/next_scale_probe_*_varfaithful.json` 与 `results/legacy_*_brokenprobe.json`）作为对照。
