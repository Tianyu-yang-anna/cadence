## 3. 判读与机制解释

- MaskGIT 微调的意外收获：**即使不用精化，微调后的权重本身就显著变强**（visible 通路训练相当于给细尺度上了 denoising 目标的正则）；
- 精化把 BD3 的"能反悔"机制引入后 WS MAUVE 明显受益，但 wiki 上打平/略降——每尺度一次成型的误差主要不在"低置信度位置"这一假设在 wiki 域成立度更低；
- 多样性诊断排除了"CFG 压多样性"假设（我们的 distinct-2 比 BD3 更贴参考分布）——剩余 MAUVE 差距应来自 GPT-2 特征空间里的局部瑕疵（段间独立采样是首要嫌疑）。

## 4. 下阶段候选（等拍板）

1. **depth-AR 段头**（半天代码 + 40min 重训）：直接消掉段间独立性——机制上正对残余 MAUVE 差距的首要嫌疑；
2. **dd@12k 补试**（续训已在跑）：训熟后按历史经验 +0.8~1.6 MAUVE；
3. 预算阶梯 4B/8B 斜率赛（谁随预算涨得快才是路线判决）；
4. 精化调度细化（只精化 q1024/自适应 K）。

## 附加披露

- dd 去噪 decoder：两次尝试均被墙钟压在欠训状态（4k/20k），欠训版实测伤分已弃用；训熟版留待后续（非本轮结论依赖项）；
- depth-AR 实现为零初始化投影 + 头切片对角读出：未微调时与原模型逐位等价（单测锁定），从 _mg 热启动 5k 步微调即得，推理 NFE 不变；
- 全部选择在 sel 集完成，final2/3/4 各配置 test 仅一枪。
